## 📈 What Updates in Real-Time

### During Simulation

1. **Simulation Control Card**
   - Status dot turns green (pulsing)
   - Progress bar fills: 0% → 100%
   - Message updates: "Processing PCAP data..."

2. **Status Cards** (Top)
   - Numbers increment
   - System health color changes
   - Severity distribution updates

3. **Attack Distribution** (Middle)
   - New bars appear
   - Chart animates
   - Percentages recalculate

4. **Alerts Table** (Bottom)
   - New rows appear at top
   - Timestamps show "just now"
   - Severity badges colored

## 🔧 Technical Details

### WebSocket Events
```javascript
// Progress updates (every second)
socket.on('mininet_progress', (data) => {
  progress: 20, 40, 60, 80, 100
  message: "Processing PCAP data..."
});

// Completion
socket.on('mininet_complete', (data) => {
  success: true
  message: "Simulation completed!"
});

// Errors
socket.on('mininet_error', (data) => {
  error: "Error message"
});
```

### State Management
```javascript
const [simulationStatus, setSimulationStatus] = useState({ active: false });
const [progress, setProgress] = useState(0);
const [progressMessage, setProgressMessage] = useState('');
const [selectedMode, setSelectedMode] = useState('normal');
const [selectedAttack, setSelectedAttack] = useState('syn_flood');
```

### API Endpoints Used
```
GET  /api/mininet/status    - Get simulation status
GET  /api/mininet/attacks   - Get available attacks
POST /api/mininet/start     - Start simulation
POST /api/mininet/stop      - Stop simulation
```
