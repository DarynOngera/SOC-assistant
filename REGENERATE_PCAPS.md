# PCAP Regeneration Plan - IPv4 Alignment

## Problem Identified
- **Attack PCAPs**: IPv6 only (generated by Mininet with default settings)
- **Normal PCAPs**: IPv4 (real network traffic)
- **Training Data**: IPv4 (CIC-IDS dataset)
- **Result**: Feature extraction fails, simulation doesn't work

## Root Cause
Mininet generates IPv6 traffic by default when no explicit IP configuration is provided.

## Solution
Regenerate ALL attack PCAPs with explicit IPv4 addressing to match:
1. Normal traffic format (IPv4)
2. Training data format (IPv4)
3. Feature extraction expectations (IPv4)

## Steps to Fix

## Key Changes Needed

### Before (IPv6 - Wrong)
```python
self.net = Mininet(
    switch=OVSSwitch,
    link=TCLink,
    autoSetMacs=True,
    autoStaticArp=True,
    controller=None
)

# No IP specified → Mininet uses IPv6
attacker = self.net.addHost('attacker')
victim = self.net.addHost('victim')
```

### After (IPv4 - Correct)
```python
self.net = Mininet(
    switch=OVSSwitch,
    link=TCLink,
    autoSetMacs=True,
    autoStaticArp=True,
    controller=None,
    ipBase='10.0.0.0/8'  # Force IPv4
)

# Explicit IPv4 addressing
attacker = self.net.addHost('attacker', ip='10.0.1.10/24')
victim = self.net.addHost('victim', ip='10.0.1.100/24')

# Disable IPv6
attacker.cmd('sysctl -w net.ipv6.conf.all.disable_ipv6=1')
victim.cmd('sysctl -w net.ipv6.conf.all.disable_ipv6=1')
```
